# Stash releases

Windows installers, signed desktop update metadata, and Android APKs for Stash.

Download the latest Windows installer or Android APK from [Releases](https://github.com/adamale15/stash-releases/releases/latest).

After installing desktop version 0.1.3 or later, use **Update** in the desktop app to install future releases. On Android, install the latest APK over your existing app.

This repository distributes release artifacts. Application source code is maintained separately.
